# LOCO AI

Web de herramientas de inteligencia artificial.

## Publicación
1. Sube todos los archivos del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub publique el sitio.

## Importante
Esta V1 contiene herramientas locales y plantillas de prompts. Para añadir generación con modelos de IA reales habrá que integrar una API y proteger las claves mediante un backend o servicio adecuado. Las páginas legales son plantillas y deben adaptarse a la situación real del proyecto.
